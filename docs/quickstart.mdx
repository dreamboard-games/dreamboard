---
title: "Quickstart"
description: "Install Dreamboard, create a game, and iterate on manifest-driven scaffolding."
---

Install Dreamboard:

```bash
npm install -g dreamboard
```

Log in:

```bash
dreamboard auth login
```

Create a project:

```bash
dreamboard project create my-game --description "A trick-taking card game"
cd my-game
```

Edit `rule.md` and `manifest.json`. Use
[CLI](/docs/reference/cli) for command behavior,
[Rule authoring](/docs/reference/rule-authoring) for the rules document and
[Manifest authoring](/docs/reference/manifest-authoring) for the manifest
schema.

Commit and push your authored source with Git:

```bash
git add .
git commit -m "Create my game"
git push -u origin main
```

Check server state for the pushed commit:

```bash
dreamboard project status --commit HEAD --wait
```

Verify the exact commit:

```bash
dreamboard verify --commit HEAD
```

Start a local server to play the project:

```bash
dreamboard dev
```

Useful follow-up commands:

- `dreamboard project clone <project>` clones an existing project repository.
- `dreamboard test` runs offline reducer tests.
- `dreamboard build --commit HEAD` creates a server build for a pushed commit.
- `dreamboard preview --commit HEAD` creates a preview for a pushed commit.

For a concise command reference, see [Dreamboard command reference](/docs/reference/cli).

For a full walkthrough, continue with
[Building your first game](/docs/tutorials/building-your-first-game).
