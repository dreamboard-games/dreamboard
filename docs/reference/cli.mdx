---
title: "Local development launcher"
description: "Project-local check and dev scripts."
---

`@dreamboard-games/dev-host` provides one local launcher, `dreamboard-dev`. Invoke it through the game's `pnpm dev` script.

| Option      | Default | Purpose                 |
| ----------- | ------- | ----------------------- |
| `--port`    | `5173`  | Loopback HTTP port      |
| `--players` | `2`     | Number of local seats   |
| `--seed`    | `1`     | Deterministic game seed |

`--options '{"target":10}'` supplies JSON initialization options declared by the game's model schema. Undeclared or invalid options are rejected at initialization.

The launcher reads `manifest.ts`, the reducer ABI in `app/index.ts`, and `ui/index.tsx` from the working directory. It bundles on page load. Refresh the browser after edits.

`pnpm check` is owned by the game project, normally `tsc --noEmit && vitest run`. There is no global product CLI and no login, sync, remote build, preview, or release command.
